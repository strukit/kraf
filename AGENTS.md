RECOMMENDED, NOT RECOMMENDED, MAY, and OPTIONAL follow RFC 2119 and RFC 8174.

This document is a constitution. A rule of this document MUST NOT be replaced by
another document and MUST NOT be bypassed by an ad-hoc exception. A rule MAY only be changed by an EXPLICIT user instruction.

## Rules

- An agent MUST give the rules of this document precedence over any skill, tool,
  agent, or instruction, unless the user gives an EXPLICIT instruction.
- An agent MUST completely reread and reload this file whenever the user explicitly instructs it to do so.
- An agent MUST follow this file's instructions in order, completing each before proceeding
- An agent MUST follow the workflow this document describes.
